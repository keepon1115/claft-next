# フェーズ12: Yononakaマップ ビジュアル改良メニュー

前提: `10-map-integration.md`。RPG・2Dドット絵路線は維持したまま「世界に意味と物語を足す」改良。
素材は CC0(Kenney各種パック、Ninja Adventure Pack)の範囲で。**見た目の変更もデータ/テキストファイル駆動**を保つ。

**V1〜V8 全項目採用確定。** 実装順序(1項目=1セッション):
**V8(道しるべ・迷子防止) → V1(ゾーン建築) → V4(黄昏時間) → V2(学びの塔) → V5(季節) → V6(音) → V7(仕事場小物) → V3(CLAFT村※9b完了後)**
※V1とV8を先にやるのは、後続機能(ラジオ塔=11-E、偉人出現=11-F)の「場所」を先に用意するため。

## 世界観の柱(3つ)

### V1. ゾーンごとのテーマ建築(こだわりの島)
各こだわりゾーンに「その生き方を象徴するランドマーク」を1つ建てる。タグの意味が風景で伝わる:

| ゾーン | ランドマーク | 意味 |
|---|---|---|
| だわりの力に | 🔨 鍛冶工房(煙突から煙) | 力を鍛え続ける |
| 技を極める職人 | 🏺 アトリエ・窯 | 手仕事の積み重ね |
| わくわくと挑戦 | 🔥 火山ふもとのベースキャンプ | 挑戦の途中である |
| 家族・地域 | 🏘 長屋と共同の井戸 | 人のそばで働く |
| 自由なはたらき方 | 🎈 気球と小さな港 | どこへでも行ける |
| 安定 | 🏛 石垣の蔵と灯台 | 積み上げと見通し |

実装: `KodawariMap.gd` のゾーン描画に建物スプライト配置を追加(位置はゾーン定義に紐づけてデータ化)。

### V2. 学びの塔(キャリア理論ゾーンの改築)
キャリア理論家5人(スーパー/クランボルツ/サビカス/シャイン/ブリッジズ)を平置きせず、**5階建ての塔**に。
1階から順に上る=理論の時代順・積み上げを体感。各階に理論家NPC+動画看板。屋上は展望台(視点をふやすへのリンク、11-E兼用)。
実装: 新シーン `LearningTower.tscn` + 各階は同一レイアウトの使い回し(データで差し替え)。

### V3. CLAFT村(メンバーの家が並ぶ区画)
フェーズ9の村人に**「自分の家」**を与える。member_avatarsのレコードがある子の家が1軒建ち、表札にニックネーム。
- 家の見た目はsprite_id(アバター)から決定論的に選ぶ(3〜4種の家テクスチャ×色)
- 家が建つ・村が埋まっていく様子がそのまま「仲間が増えた」可視化になる(11-Dの成長する村と相性◎)
- 実装: 起動時のmember_avatars取得(9bで実装済みの仕組み)から家も生成。再書き出し不要

## 空気感(5つ)

### V4. 黄昏時間(小・CLAFTらしさ)
実時刻に連動して `CanvasModulate` で色温度を変える(朝=白、昼=明、17-19時=オレンジの黄昏、夜=紺+家の窓に灯り)。
**夕方のマップで「黄昏の対話室」への渡り廊下が現れる**…という他機能への粋な導線も可能(息抜きグループとの連携)。

### V5. 季節の演出(小)
月に応じてパーティクルと色味を切替(4月=桜吹雪、夏=木漏れ日強め、12-2月=雪、`CPUParticles2D`)。
「久しぶりに開いたら季節が変わっていた」= 世界が生きている感。

### V6. 音(小〜中)
環境音(鳥・風・広場のざわめき)+足音+会話開始のポワン音。Kenney Audio(CC0)。
Web版は初回タップまで音声再生不可(ブラウザ仕様)なので、タイトルの「はじめる」ボタンで解禁する作り。

### V7. NPCの仕事場ミニセット(中)
大人NPCの周囲に、その人の仕事を表す小物を2〜3個置く(パン屋なら竈と麦袋)。
npcs.jsonに `props: ["oven","wheat"]` を足し、propスプライト辞書から描画。**JSON追記だけで新NPCの世界が作れる**状態を保つ。

### V8. 道しるべ・地図表示(小)
分岐点の看板を「→ 職人の道」等の方向表示に整備+Mキーで簡易全体マップ(現在地の点だけ)。
迷子防止。ただし構想書の「ぶらぶら歩いて偶然出会う」哲学を壊さないよう、NPCの位置は地図に**載せない**。

## 実装時の共通注意

- タイル・建物素材の第一候補: Kenney Tiny Town / Pixel Platformer Farm 等(CC0)。ダウンロードはオーナー、配置指示はSonnet
- スプライト追加時は `assets/tiles/` `assets/objects/` の既存規約に従う(README.md参照)
- 全変更後にオーナーの動作確認(F5)→Web書き出しが必要
- V1のランドマークにはラジオ塔(11-E)を含める。V2の屋上展望台も11-Eの導線を兼ねる
- 偉人(11-F)の出現候補地は各ゾーンのランドマーク付近とする(「エジソンは鍛冶工房の裏にいた」という記憶に残る出会い)
