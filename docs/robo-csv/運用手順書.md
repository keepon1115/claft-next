# ロボクエスト コンテンツ運用手順書（非エンジニア向け）

テーマ・設問の追加や修正は、プログラムを触らずスプレッドシートとCSVだけで完結します。

---

## 1. 全体の流れ

```
Googleスプレッドシートで編集
  → 「ファイル」→「ダウンロード」→「カンマ区切り値（.csv）」
  → 管理画面の「CSVインポート」にアップロード
  → プレビューで内容を確認
  → 「この内容で反映する」
```

テーマと設問は別々のシート（タブ）・別々のCSVファイルとして管理します。片方だけの更新でもインポートできます。

---

## 2. テーマCSVの書き方

サンプル：`テーマ-テンプレート.csv`

| 列名 | 内容 | 例 |
|---|---|---|
| level | レベル番号（1〜8） | `1` |
| theme_number | そのレベル内でのテーマ番号 | `1` |
| title | テーマ名 | `信号機をつくろう` |
| 問い | 「正解が一つでない問い」の本文 | `もし信号がなかったら？` |
| 問い画像URL | 問いの下に出す画像（任意） | microCMSのURL |
| 事例解説 | 「正解じゃないけど、こんな見方もあるよ」の文章 | 自由記述 |
| 事例解説画像URL | 同じ場所に出す画像（任意・推奨） | microCMSのURL |
| アイコン画像URL | マップに出すアイコン画像（任意） | microCMSのURL |
| アイコン絵文字 | 画像がないときの代わりの絵文字 | `🚦` |
| 公開 | 生徒に見せるなら`1`、まだなら`0` | `1` |
| 表示順 | マップでの並び順（小さい方が先） | `1` |

**同じ `level` と `theme_number` の組み合わせを持つ行は「上書き更新」になります。** 新しいテーマを増やすときは、これまでにない `level-theme_number` の組み合わせにしてください。

---

## 3. 設問CSVの書き方

サンプル：`設問-テンプレート.csv`

| 列名 | 内容 | 例 |
|---|---|---|
| テーマ | どのテーマの設問か。`level-theme_number` の形式 | `1-1` |
| 設問番号 | そのテーマの中で何問目か（1問目なら1） | `1` |
| 問題文 | 設問の本文 | |
| 選択肢1〜3 | 3つの選択肢 | |
| 正解 | 正解の選択肢の番号（1・2・3のどれか） | `2` |
| 解説 | 回答後に表示する解説文（任意） | |
| 画像URL | 設問に添える画像（任意） | microCMSのURL |
| 動画URL | 設問に添えるYouTube動画（任意。画像より優先表示） | `https://www.youtube.com/watch?v=...` |
| 参照ページ | 教材の参照ページ表記（任意） | `P.13` |

**「テーマ」列は、先にテーマCSVで作成済み（またはテーマCSVを同時にアップロード）のテーマを指定してください。** 存在しないテーマ番号を指定するとエラーになります。

**同じ「テーマ」＋「設問番号」の組み合わせを持つ行は「上書き更新」になります。**

---

## 4. 画像の準備（microCMS）

1. microCMS管理画面 → 画像をアップロード
2. アップロードした画像のURLをコピー
3. スプレッドシートの該当セルに貼り付け

CSVには**画像ファイルそのものではなく、URL（文字列）だけ**を入れます。

---

## 5. 動画の準備（YouTube）

YouTubeにアップロードした動画のURLをそのまま「動画URL」列に貼り付けてください。以下のどの形式でも構いません。

- `https://www.youtube.com/watch?v=XXXXXXXXXXX`
- `https://youtu.be/XXXXXXXXXXX`
- `https://www.youtube.com/shorts/XXXXXXXXXXX`

---

## 6. インポート画面での注意点

- **プレビュー画面で必ず内容を確認してから「反映する」を押してください。** プレビューの時点ではまだDBに書き込まれません。
- 行に赤色のエラーが出ている場合、その行（と場合によっては他の行も）は反映されません。エラー内容を読んでCSVを直し、もう一度アップロードしてください。
- **CSVに書かれていない既存のテーマ・設問は消えません。** 消したい場合は管理画面から個別に削除してください。
- 同じCSVをもう一度アップロードしても、内容が同じであれば「更新」として扱われるだけで、行が増えることはありません。
