## 管理画面概要

CLAFT 管理画面は、システムの運営管理を効率的に行うための統合管理ツールです。

### 🎯 主な機能

- **クエスト承認管理**: ユーザーから提出されたクエストの承認・却下
- **ユーザー管理**: 登録ユーザーの情報確認と管理
- **データ分析**: システム利用状況の統計とレポート
- **承認履歴追跡**: 過去の承認作業の履歴確認
- **リアルタイム更新**: 最新の状況を自動で反映

### 🔧 技術仕様

- **リアルタイム同期**: Supabase リアルタイム機能で即座に更新
- **レスポンシブデザイン**: PC・タブレット・スマートフォン対応
- **セキュアアクセス**: 管理者権限による安全な操作環境

## アクセス方法

### 1. 管理画面へのログイン

1. **URL**: `https://your-domain.com/admin` にアクセス
2. **認証**: 管理者権限を持つアカウントでログイン
3. **権限確認**: 管理者権限が自動で確認され、ダッシュボードが表示

### 2. 権限管理

```
管理者権限の付与は以下の手順で行います：
1. Supabase ダッシュボードにログイン
2. admin_users テーブルに管理者情報を追加
3. is_active = true に設定
```

### 3. セキュリティ

- 管理者アカウントは厳重に管理してください
- 定期的なパスワード変更を推奨します
- 不要なアクセスは即座に無効化してください

## 基本操作

### 🖱️ ナビゲーション

#### 統計カードクリック
```
各統計カードをクリックすると関連タブに移動:
• 総ユーザー数 → ユーザー管理タブ
• 承認待ちクエスト → クエスト承認タブ
• 完了クエスト → 承認履歴タブ
• 平均進捗率 → データ分析表示
```

#### クイックアクション
```
よく使う機能への即座アクセス:
🟢 承認待ちクエスト (バッジ付き)
🔵 ユーザー管理
⚫ 承認履歴
🟡 使い方ガイド
```

### 🔄 データ更新

- **自動更新**: リアルタイムでデータが自動更新
- **手動更新**: 各セクションの「更新」ボタンで強制更新
- **バックグラウンド同期**: 他の管理者の操作も即座に反映

## クエスト承認作業

### 📝 承認フロー

```
1. ユーザーがクエストを提出
    ↓
2. 管理画面に承認待ちとして表示
    ↓
3. 管理者が内容を確認
    ↓
4. 承認 or 却下を決定
    ↓
5. 次のステージが自動解放 (承認の場合)
```

### ✅ 個別承認操作

#### 承認手順
1. **クエスト承認タブ**を選択
2. 承認待ちリストからクエストを確認
3. **承認ボタン**をクリック
4. 確認ダイアログで「OK」
5. 完了通知を確認

#### 却下手順
1. **却下ボタン**をクリック
2. 却下理由を入力 (必須)
3. 「OK」で確定
4. ユーザーに通知が送信

### 📦 一括承認操作

#### 一括承認の手順
```
1. チェックボックスで複数選択
   ┌─ 全選択: ヘッダーのチェックボックス
   └─ 個別選択: 各行のチェックボックス

2. 「一括承認」ボタンをクリック

3. 確認ダイアログで処理内容を確認

4. 処理結果の通知を確認
   • 成功件数
   • 失敗件数
   • エラー詳細 (該当する場合)
```

### 🔍 フィルタリング機能

#### ユーザー検索
```
• ニックネーム部分一致検索
• メールアドレス部分一致検索
• リアルタイム検索 (入力と同時に絞り込み)
```

#### ステージフィルター
```
• 全ステージ表示
• 特定ステージのみ表示 (1-12)
• 承認待ちの分布確認に活用
```

#### 日付フィルター
```
• 特定日の提出分のみ表示
• 期間を指定した絞り込み
• 処理優先度の判断に活用
```

## トラブルシューティング

### ⚠️ よくある問題と解決策

#### 1. 承認処理が失敗する
```
症状: 承認ボタンを押してもエラーが発生する

原因:
• ネットワーク接続の問題
• 権限の期限切れ
• データベース接続エラー

解決策:
1. ページを再読み込み
2. ログアウト → 再ログイン
3. ネットワーク接続を確認
4. 別のブラウザで試行
```

#### 2. データが更新されない
```
症状: 最新の情報が表示されない

原因:
• ブラウザキャッシュの問題
• リアルタイム接続の切断

解決策:
1. 「更新」ボタンをクリック
2. Ctrl+F5 でハードリロード
3. ブラウザキャッシュをクリア
```

#### 3. 一括承認でエラーが発生
```
症状: 一括承認で一部が失敗する

原因:
• 処理中に状態が変更された
• 権限不足のクエストが含まれている

解決策:
1. エラーメッセージを確認
2. 失敗したクエストを個別処理
3. データの整合性を確認
```

### 🔧 エラーコードと対処法

```
ERROR_AUTH_EXPIRED
→ ログアウトして再ログイン

ERROR_PERMISSION_DENIED
→ 管理者権限を確認

ERROR_NETWORK_TIMEOUT
→ ネットワーク接続を確認

ERROR_DATA_CONFLICT
→ ページを再読み込みして最新状態で再試行
```

### 📞 サポート連絡先

```
システムエラーの場合:
• 開発チームまで連絡
• エラーメッセージの詳細を報告
• 再現手順を記録

運用上の質問:
• 管理者ガイドを再確認
• 操作ログを確認
• 必要に応じて開発チームに相談
```
